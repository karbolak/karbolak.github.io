DiffGate score demo

DiffGate scores the trajectory at step five of 25. A score below the threshold stops the run. Change the example or threshold to see the outcome, then replay it step by step.

Example prompt

A medieval knight riding a corgi through misty forest at sunrise, highly detailed fantasy illustration.

diffgate / score-features

$ diffgate score-features --features features.json
Steps 1–5 · ScoreSteps 6–25

Aborted at step 5

The score fell below the quality threshold. Try another example or lower the threshold.

Edit feature JSON

The browser runs the default uncalibrated scorer on example features. The replay illustrates its stop decision without running an image model.
